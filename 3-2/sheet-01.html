학번이름

칠판 화면에 번호가 열리면 같은 번호 빈칸에 받아 적으세요. (빈칸 1~14)

① 사물 인터넷 — 할머니의 스마트 온실

  • 온도·토양 수분·카메라 센서가 쉬지 않고 잰다 → 제어기가 규칙과 견주어 → 환기창 모터·물 밸브·로봇 팔을 움직인다
  • 사물에 센서와 통신 기능을 넣어 서로 정보를 주고받게 하는 기술 → 사물 인터넷(IoT)
  • ‘35℃ 이상이면 연다’ → 한낮에 30℃를 넘는 시간 약 8시간 · ‘24℃ 이상이면 연다’ → 알맞은 온도(18~28℃) 15시간
  • 센서 값을 사람이 정해 둔 규칙과 견주어 장치를 움직인다 (기준값은 사람이 정한다)
  • 물 주기(한 번에 30 L): 타이머 방식 하루 8번 240 L → 센서 규칙 하루 3번 90 L · 물·에너지 같은 자원의 낭비를 줄인다

② 인공지능 — 익은 딸기를 가려내는 선

  • 사람처럼 학습·추론·판단하도록 만든 컴퓨터 기술 → 인공지능
  • 할머니가 익음/안 익음을 표시한 딸기 40개(가로 붉은 정도, 세로 크기) → 기계가 배우는 학습 데이터
  • 선을 그어 놓고 틀린 만큼 조금씩 옮기기를 되풀이 → 40개 중 38개를 맞히는 선. 데이터에서 규칙(선)을 스스로 찾는 방법 → 기계 학습

③ 유용성과 한계

시험정확도무슨 일이?
처음 보는 빨간 품종 40개98%학습한 것과 비슷한 상황에서는 잘 맞는다
흰 딸기 품종 30개50%다 익은 흰 딸기 15개를 모두 ‘안 익음’으로 판단
흰 딸기 표본 20개를 더해 다시 학습빨강 98% · 흰 87%선이 누웠다 (붉은 정도보다 크기를 더 본다)
  • 학습 데이터에 흰 딸기가 없었다. 데이터가 치우치면 판단도 치우친다 → 데이터 편향
  • 무엇이 빠졌는지 알아채고, 결과를 점검하고, 책임지는 일 → 사람의 몫
  • 기술이 삶과 환경을 개선하는 쓸모 → 유용성
  • 삶의 개선: 의료 영상 판독, 재난 수색 로봇, 유전 정보에 맞춰 치료하는 맞춤형 의료
  • 환경 개선: 스마트팜, 지능형 전력망, 태양광·풍력 전기를 모았다가 쓰는 에너지 저장 장치
  • 함께 대비해야 할 한계·우려: 연결된 기기의 해킹(사생활·안전), 데이터 편향, 일자리 변화, 데이터 센터의 많은 전력

문제로 확인하기

1. 센서 규칙으로 물을 준 온실이 타이머 방식보다 물을 적게 쓴 까닭은? (한 번에 주는 양은 같다) → ㉡
㉠ 한 번에 주는 물의 양을 줄여서   ㉡ 흙이 마를 때에만 물을 줘서   ㉢ 환기창을 닫아 두어서

2. 빨간 딸기 40개로만 학습한 로봇이 흰 딸기에서 50%만 맞힌 까닭은? → 학습 데이터에 흰 딸기가 없어서(데이터 편향)
