개념정리 학습지 · 산화와 환원

학번이름

칠판 화면에 번호가 열리면 같은 번호 빈칸에 받아 적으세요. (빈칸 1~14)

① 산소의 이동 — 용광로에서 철을 꺼내기

  • 철광석의 주성분은 산화 철(Ⅲ) Fe₂O₃ (질량의 약 70%가 철, 30%가 산소) → 철을 얻으려면 철에 붙은 산소를 떼어 가야 한다
  • 코크스(C) + 공기의 산소 → 일산화 탄소(CO) 2C + O₂ → 2CO
  • CO가 철광석의 산소를 떼어 가 CO₂가 된다 Fe₂O₃ + 3CO → 2Fe + 3CO₂
  • 산소를 얻는 반응 → 산화 (CO → CO₂)  ·  산소를 잃는 반응 → 환원 (Fe₂O₃ → Fe)
  • 한쪽이 잃은 산소는 다른 쪽이 얻는다 → 산화와 환원은 항상 동시에 일어난다
  • 용광로 장부(단원 화면 모형): 철광석 160 kg을 남김없이 철로 바꾸는 코크스 최소 36 kg → 얻는 철 112 kg
    철 280 kg이 필요하면 모두 2.5배: 철광석 400 kg + 코크스 90 kg

② 역사를 바꾼 세 사건 — 공통점은 산소의 이동

사건반응식산화되는 것 / 환원되는 것
철의 제련Fe₂O₃ + 3CO → 2Fe + 3CO₂산화: CO → CO₂ / 환원: Fe₂O₃ → Fe
화석 연료의 연소CH₄ + 2O₂ → CO₂ + 2H₂O산화: 메테인이 산소를 얻는다 (연소 = 빠른 산화)
광합성6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂환원: 이산화 탄소 → 포도당 / 산화: 물 → 산소 기체
  • 산화: 녹, 손난로(철 가루 → 산화 철), 세포 호흡(포도당 → CO₂) · 환원: 구리 제련(CuO → Cu)

③ 전자의 이동 — 철 못에 구리를 입히기

  • 파란 황산 구리(Ⅱ) 수용액에 철 못 → 못 표면에 붉은 구리, 파란색(Cu²⁺)이 옅어짐
    산소가 없어도 전자를 잃으면 산화, 얻으면 환원
  • 산화: Fe → Fe²⁺ + 2e⁻  ·  환원: Cu²⁺ + 2e⁻ → Cu  ·  전체: Fe + Cu²⁺ → Fe²⁺ + Cu
  • 구리 선 + 질산 은 수용액: Cu + 2Ag⁺ → Cu²⁺ + 2Ag → 구리 원자 1개당 은 이온 2개가 은이 된다
  • 전자를 잃고 양이온이 되려는 정도 → 금속의 반응성   큰 것부터: Mg > Zn > Fe > Cu > Ag

문제로 확인하기

1. 아연 조각을 푸른 황산 구리(Ⅱ) 수용액에 넣으면? → ㉠
㉠ 아연 표면에 구리가 달라붙는다   ㉡ 아무 변화가 없다   ㉢ 용액의 파란색이 더 진해진다

2. CH₄ + 2O₂ → CO₂ + 2H₂O 에서 산소를 얻어 산화되는 물질은? → ㉠ CH₄
㉠ CH₄   ㉡ CO₂   ㉢ H₂O
